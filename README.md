# Custom C Spellchecker (Double-Hashing Implementation)

A high-performance, command-line spellchecking utility built in C. This project implements a custom hash table using open addressing and double hashing to achieve rapid dictionary lookups and efficient collision resolution.

## Quick Start

Since this project uses a structured `Makefile`, compiling and running the application requires only a couple of terminal commands.

### Prerequisites
Make sure you have `gcc` and `make` installed on your system (standard on macOS/Linux).

### Installation & Compilation
1. Clone or download this directory.
2. Open your terminal in the project root folder and compile the project:
   ```bash
   make

### Running the Application
To launch the spellchecker, execute the binary from the root folder:
```bash
./Build/spellcheck
